# Librarian usability sessions: protocol (design-only)

**Status: design-only.** Not held. Participants need workspace accounts with `CAN USE` on both apps.

| Item | Plan |
| --- | --- |
| Participants | 5 NAL metadata librarians who handle PubAg corrections; none involved in building the tool |
| Setting | Remote, screen shared, 30 minutes each; think-aloud; one observer takes notes |
| Tasks | T1-T4 from [`HEURISTIC_REVIEW_2026-11-21.md`](HEURISTIC_REVIEW_2026-11-21.md), plus T5: paste a cut-off SRU response and recover |
| Notices | 5 per participant, drawn from Sample 1 rows not shown in the demo (one bare notice, one already annotated) |
| Measures | Task success (yes / with help / no), time per task, errors, System Usability Scale (10 items), and what each librarian would change |
| Comparison | Time per notice with the tools against the librarian's usual manual process for the same notices |
| Records | One JSON file per session in `../results/usability/` (no names; participant P1-P5), plus a summary here |
| Acceptance reading | With 5 participants report counts, not percentages; any task failed by 2 or more participants is a design problem to fix first |
