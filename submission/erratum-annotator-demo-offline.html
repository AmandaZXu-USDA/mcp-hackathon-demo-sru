How it works
  1. Find: the SRU search for the notice (built by the companion tool, mcp-sru-syntax) returns the correction notice and the original article.
  2. Match: the original is the record whose DOI the notice cites; otherwise the most similar title. Uncertain matches are flagged for review, never guessed.
  3. Annotate: the date, volume, issue, pages and DOI of the correction become the note [Erratum: ...] at the end of the original title. Titles that already have a note are left alone.

Same rules everywhere: this page, the MCP server mcp-erratum-note (7 read-only tools at /mcp, for Genie Code and other AI clients), the Supervisor Agent agent-erratum-annotator (chat), and the Unity Catalog function users.amanda_xu.process_sru_response (SQL, for long lists). Evaluation on 53 librarian-checked notices: 50/53 exact annotated titles from the agent; 0 errors and 48/48 original MMS IDs from the MCP server.
